# Level 1 — Basic: NumPy Foundations and Loading Data

**Notebook:** `level1_numpy_and_loading.ipynb` &nbsp;·&nbsp; **Datasets:** `student_performance.csv`, `weather_data.csv`
&nbsp;·&nbsp; **Suggested time:** 3–4 hours

## Topics
- Creating arrays: `arange`, `zeros`, `ones`, `linspace`, `eye`, `reshape`
- Indexing, slicing and boolean masks
- Vectorised arithmetic and why it beats loops
- Broadcasting rules
- Aggregations along an axis (`sum`, `mean`, `max`, `argmax`)
- `np.where` and `np.select`
- Random numbers with a seed and descriptive statistics
- Loading a CSV with Pandas: `head`, `tail`, `shape`, `info`, `describe`, `value_counts`
