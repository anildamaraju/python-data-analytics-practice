# Datasets

All three datasets are **synthetic**. They were generated by `generate_datasets.py` with a fixed random seed, so they are
identical every time they are regenerated. They are realistic on purpose:

- **Sales** has a festive-season peak in October–November.
- **Weather** follows real Indian patterns. Chennai's rain peaks in October–November, Mumbai has heavy south-west monsoon
  rain, and Delhi has the largest seasonal temperature swing.
- **Student performance** includes believable links between attendance, study habits and marks.

> ⚠️ **The raw files contain deliberate data-quality problems** (listed under each dataset). Finding and fixing them is
> part of the coursework. Never edit the CSV files by hand. Clean them in code.

To regenerate the files (for example after changing the generator):

```bash
python datasets/generate_datasets.py
```

---

## 1. `sales_data.csv` — 1,215 rows × 11 columns

Orders from a retail business with outlets in 15 Indian cities, January–December 2024.

| Column | Type | Description |
|---|---|---|
| `Order_ID` | text | Unique order number (`ORD10001` …) |
| `Order_Date` | date (text, `YYYY-MM-DD`) | Date the order was placed |
| `Region` | text | North, South, East, West, Central |
| `City` | text | City of the outlet (3 per region) |
| `Customer_Segment` | text | Consumer, Corporate, Small Business |
| `Category` | text | Electronics, Furniture, Office Supplies, Clothing |
| `Product` | text | Product name (18 products) |
| `Quantity` | number | Units ordered |
| `Unit_Price` | number (Rs.) | Price per unit before discount |
| `Discount` | number (0–0.20) | Discount rate applied to the order |
| `Payment_Mode` | text | UPI, Credit Card, Debit Card, Cash, Net Banking |

**Data-quality problems to find:** exact duplicate rows · `Region` with inconsistent case and stray spaces ·
`Unit_Price` stored as text because some values carry an `Rs.` prefix · missing `Quantity`, `Unit_Price` and `Customer_Segment`.

## 2. `student_performance.csv` — 246 rows × 13 columns

One semester of results for B.Tech CSE Sections A and B (120 students each).

| Column | Type | Description |
|---|---|---|
| `Student_ID` | text | `CSEA001` … `CSEB120` |
| `Section` | text | A or B |
| `Gender` | text | Male / Female |
| `Accommodation` | text | Hosteller or Day Scholar |
| `Internet_Access` | text | Yes / No (internet access at home) |
| `Attendance_Pct` | number (0–100) | Attendance percentage for the semester |
| `Study_Hours_Per_Week` | number | Self-reported study hours per week |
| `Previous_GPA` | number (0–10) | GPA from the previous semester |
| `Mathematics`, `Physics`, `Programming`, `English`, `Electronics` | number (0–100) | End-semester marks; blank = absent |

**Data-quality problems to find:** duplicate rows · `Gender` coded several ways (`Male`, `M`, `m`, `female` …) ·
impossible attendance values (above 100% or negative) · impossible marks (−1, 150) · missing marks (absent) and missing study hours.

## 3. `weather_data.csv` — 2,934 rows × 7 columns

Daily weather for **Hyderabad, Chennai, Delhi and Mumbai**, 1 Jan 2023 – 31 Dec 2024.

| Column | Type | Description |
|---|---|---|
| `Date` | date (text, `YYYY-MM-DD`) | Day of the observation |
| `City` | text | Hyderabad, Chennai, Delhi, Mumbai |
| `Max_Temp_C` | number (°C) | Daily maximum temperature |
| `Min_Temp_C` | number (°C) | Daily minimum temperature |
| `Humidity_Pct` | number (%) | Average relative humidity |
| `Rainfall_mm` | number (mm) | Total rainfall for the day |
| `Wind_Speed_kmh` | number (km/h) | Average wind speed |

**Data-quality problems to find:** duplicate rows · missing readings in every measurement column ·
the sensor error code `-99` in `Max_Temp_C` and `Humidity_Pct`. It must not be treated as a real temperature.
